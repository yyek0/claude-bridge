# Claude Bridge

В левой панели VS Code откройте **Claude Bridge**. Кнопка **?** в заголовке ведёт в руководство с отдельной установкой для macOS и Windows, настройкой VPS и получением ключа Claude API. [Открыть руководство](https://github.com/yyek0/claude-bridge/blob/main/docs/guide.md)

Для подключения к уже настроенному backend откройте SSH-туннель и вставьте выданный на VPS токен **cb_…** через **Подключить**. По умолчанию расширение использует `ws://127.0.0.1:18765/ws`.

Наведите указатель на **+**, **↥**, **⌗** или **×**, чтобы увидеть назначение кнопки. Локальные инструменты доступны для выбранной доверенной папки. Правки показываются через VS Code Diff, а запуск команд требует подтверждения.
