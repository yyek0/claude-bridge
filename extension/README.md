# Claude Bridge

Откройте боковую панель **Claude Bridge**, выполните **Подключить устройство** и введите токен устройства, выданный администратором backend. По умолчанию расширение подключается к `ws://127.0.0.1:18765/ws` через SSH-туннель. Подробная установка для macOS и Windows находится в README исходного проекта.

Локальные инструменты доступны для доверенной рабочей папки. Перед отправкой запроса выберите папку и включите доступ к ней. Каждое изменение открывается в VS Code Diff. Команды запускаются только после подтверждения.
