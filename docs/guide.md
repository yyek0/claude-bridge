# Claude Bridge с нуля

Claude Bridge состоит из двух частей. **Расширение** устанавливается в VS Code на вашем Mac или Windows. **Backend** работает на вашем Ubuntu VPS. Терминал на компьютере открывает SSH-туннель между ними.

**Если backend на вашем VPS уже установлен**, сразу переходите к [macOS](#macos) или [Windows](#windows). В процессе вам всё равно понадобится выданный на сервере токен устройства. **Если сервер новый**, сначала выполните [настройку Ubuntu VPS](#ubuntu-vps).

## Что подготовить

1. Скачайте [ZIP проекта](https://github.com/yyek0/claude-bridge/archive/refs/heads/main.zip) и распакуйте. Откройте папку, в которой видны `README.md`, `desktop` и `artifacts`. Обычно она называется `claude-bridge-main`.
2. Запишите **IP-адрес VPS**, **SSH-логин** и **SSH-порт** из панели хостинга. В примерах ниже используются `203.0.113.10`, `ubuntu` и `22`. Вставляйте свои значения. Если хостинг выдал логин `root`, укажите `root` вместо `ubuntu`.
3. Найдите файл `artifacts/claude-bridge-0.1.1.vsix` в распакованной папке. Можно отдельно [скачать VSIX 0.1.1](https://github.com/yyek0/claude-bridge/raw/refs/heads/main/artifacts/claude-bridge-0.1.1.vsix). Архив `claude-bridge-server-0.1.0.tar.gz` из папки `artifacts` понадобится только для установки backend на VPS.

### Что куда вводить

| Данные | Где взять | Куда вводить |
| --- | --- | --- |
| IP, SSH-логин и SSH-порт | Панель вашего VPS | Файл `desktop/.env` на компьютере |
| Пароль SSH или приватный SSH-ключ | Хостинг или настройки доступа к VPS | Пароль в приглашение `ssh` в терминале. Если вход по ключу уже настроен, SSH использует этот ключ |
| Токен **Claude Bridge**, начинается с `cb_` | Команда `/opt/claude-bridge/admin add` на вашем VPS | Кнопка **Подключить** в расширении VS Code |
| Ключ **Claude API**, обычно начинается с `sk-ant-` | Страница **API Keys** в Claude Console | Строка `ANTHROPIC_API_KEY=` в `/etc/claude-bridge/backend.env` на VPS |
| Пароль удалённого рабочего стола, если установлен XFCE | Команда `sudo passwd bridge-desktop` на VPS или пароль, выданный администратором | Клиент удалённого рабочего стола, логин `bridge-desktop` |

Для первого запуска можно использовать модель **mock · mock**. Она проверяет подключение и локальные инструменты без покупки подписки и без ключа Claude API.

## macOS

### 1. Установите расширение

1. Если VS Code ещё не установлен, скачайте его для **macOS** с [официального сайта](https://code.visualstudio.com/download), распакуйте и перенесите в **Программы**.
2. Откройте VS Code. Нажмите **Cmd+Shift+P** и найдите **Extensions: Install from VSIX…**. Эту же команду можно открыть через значок расширений слева и меню **… → Install from VSIX…**.
3. В окне выбора файла откройте распакованную папку проекта, затем `artifacts` и выберите **claude-bridge-0.1.1.vsix**. Если VS Code попросит перезагрузить окно, нажмите **Reload**. На левой панели появится значок моста **Claude Bridge**.

### 2. Укажите свой VPS и откройте туннель

Откройте приложение **Terminal**. Если ZIP распакован в **Загрузки**, выполните:

```sh
cd ~/Downloads/claude-bridge-main
test -f desktop/.env || cp desktop/.env.example desktop/.env
open -e desktop/.env
```

Если папка находится в другом месте, введите `cd ` с пробелом, перетащите распакованную папку из Finder в окно Terminal и нажмите Enter. В открытом файле `desktop/.env` замените значения справа от знаков `=` и сохраните **Cmd+S**.

```dotenv
BRIDGE_SSH_HOST=203.0.113.10
BRIDGE_SSH_USER=ubuntu
BRIDGE_SSH_PORT=22
```

Если этот Mac ещё не подключался к VPS, выполните `ssh -p 22 ubuntu@203.0.113.10` со своими данными. При первом входе сверьте показанный ключ хоста с командой из [раздела Ubuntu VPS](#ubuntu-vps), затем подтвердите и выполните `exit`. Если подключение уже было настроено, этот шаг можно пропустить.

В том же Terminal запустите:

```sh
./desktop/connect-macos.sh --chat
```

Введите **пароль SSH**, если Terminal попросит. Символы при вводе пароля обычно не отображаются. Оставьте окно открытым. В соседней вкладке Terminal проверка `curl http://127.0.0.1:18765/healthz` должна вернуть `{"status":"ok","protocol":1}`.

### 3. Вставьте токен в VS Code

1. Получите токен для Mac [командой на VPS](#выпустите-токены-устройств), используя метку `macOS`.
2. В VS Code нажмите значок моста **Claude Bridge → Подключить**. Вставьте только значение поля `token`, начиная с `cb_`, и нажмите **Enter**. Кавычки и остальные поля JSON копировать не нужно.
3. Дождитесь зелёной точки и текста **Сервер подключён**. В нижнем списке **Модель** выберите **mock · mock**, введите «Привет» и нажмите **Отправить** или **Cmd+Enter**.

## Windows

### 1. Установите расширение и проверьте SSH

1. Если VS Code ещё не установлен, скачайте **Windows User Installer** для своей архитектуры с [официального сайта](https://code.visualstudio.com/download).
2. Откройте VS Code. Нажмите **Ctrl+Shift+P** и найдите **Extensions: Install from VSIX…**. В окне выбора файла откройте распакованную папку проекта, затем `artifacts` и выберите **claude-bridge-0.1.1.vsix**. Нажмите **Reload**, если VS Code предложит. Слева появится значок моста **Claude Bridge**.
3. Откройте **PowerShell** или вкладку PowerShell в **Windows Terminal** и выполните `ssh -V`. Если команда не найдена, установите компонент **Клиент OpenSSH** в дополнительных компонентах Windows. Или запустите PowerShell от имени администратора и выполните команду ниже. Остальные шаги выполняйте в обычном PowerShell. [Инструкция Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
```

### 2. Укажите свой VPS и откройте туннель

Если ZIP распакован в **Загрузки**, в обычном PowerShell выполните:

```powershell
Set-Location "$HOME\Downloads\claude-bridge-main"
if (-not (Test-Path .\desktop\.env)) { Copy-Item .\desktop\.env.example .\desktop\.env }
notepad .\desktop\.env
```

Если распаковали в другое место, откройте папку с `README.md` в Проводнике, введите `powershell` в адресную строку и нажмите Enter. Затем выполните последние две команды из блока. В Блокноте замените значения справа от знаков `=`, нажмите **Ctrl+S** и закройте файл. Его имя должно быть `.env` в папке `desktop`.

```dotenv
BRIDGE_SSH_HOST=203.0.113.10
BRIDGE_SSH_USER=ubuntu
BRIDGE_SSH_PORT=22
```

Если этот компьютер ещё не подключался к VPS, выполните `ssh -p 22 ubuntu@203.0.113.10` со своими данными. Сверьте ключ хоста по [разделу Ubuntu VPS](#ubuntu-vps) при первом подключении. После успешного входа выполните `exit`.

Откройте туннель. Введите пароль SSH, если PowerShell попросит, и оставьте окно открытым.

```powershell
.\desktop\connect-windows.ps1 -Chat
```

Если Windows блокирует запуск `.ps1`, откройте тот же туннель командой ниже. Подставьте свой IP, логин и порт. Менять политику PowerShell для этого не требуется.

```powershell
ssh -N -T -p 22 -o StrictHostKeyChecking=yes -o ExitOnForwardFailure=yes -L 127.0.0.1:18765:127.0.0.1:18765 ubuntu@203.0.113.10
```

В новом окне выполните `Invoke-RestMethod http://127.0.0.1:18765/healthz`. Значение `status` должно быть `ok`.

### 3. Вставьте токен в VS Code

1. Получите токен для Windows [командой на VPS](#выпустите-токены-устройств), используя метку `Windows`.
2. В VS Code нажмите значок моста **Claude Bridge → Подключить**. Вставьте только значение `token`, начиная с `cb_`, и нажмите **Enter**.
3. При статусе **Сервер подключён** выберите **mock · mock** в списке **Модель**, введите «Привет» и нажмите **Отправить** или **Ctrl+Enter**.

## Ubuntu VPS

Если кто-то уже установил backend, выполните вход по SSH, проверьте `/healthz` и переходите к [выпуску токена](#выпустите-токены-устройств). Установка нужна один раз на VPS. Mac и Windows могут пользоваться одним backend.

### Войдите на сервер

Для первой проверки ключа откройте веб-консоль VPS через панель хостинга и выполните там:

```sh
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

На своём компьютере откройте Terminal или PowerShell и выполните команду со своими данными. При первом входе сравните отпечаток, который показывает SSH, с отпечатком из веб-консоли. Подтвердите совпадение, затем введите пароль, если его запросили.

```sh
ssh -p 22 ubuntu@203.0.113.10
```

После удачного входа команды выполняются **на VPS**. Команда `exit` возвращает вас на компьютер.

### Установите backend на новом VPS

1. На **своём компьютере** перейдите в распакованную папку проекта. Если в терминале открыт SSH-сеанс из предыдущего шага, сначала выполните `exit`. Передайте архив на VPS. В командах `scp` порт указывается с заглавной буквой `-P`.

   Mac:

   ```sh
   scp -P 22 ./artifacts/claude-bridge-server-0.1.0.tar.gz ubuntu@203.0.113.10:~/
   ```

   Windows:

   ```powershell
   scp -P 22 .\artifacts\claude-bridge-server-0.1.0.tar.gz ubuntu@203.0.113.10:~/
   ```

2. Войдите командой `ssh` из предыдущего раздела. Выполните команды **на Ubuntu VPS**. Если вы уже вошли как `root`, команды с `sudo` можно выполнить напрямую.

   ```sh
   mkdir -p ~/bridge-release
   tar -xzf ~/claude-bridge-server-0.1.0.tar.gz -C ~/bridge-release
   cd ~/bridge-release
   sudo bash deploy/install.sh
   curl http://127.0.0.1:18765/healthz
   ```

3. Убедитесь, что ответ содержит `"status":"ok"`. Пока модель **mock · mock** включена по умолчанию, можно подключать VS Code без настройки Anthropic.

### Выпустите токены устройств

Введите на **VPS** одну команду для каждого компьютера, который хотите подключить.

```sh
sudo /opt/claude-bridge/admin add --account personal --label macOS
sudo /opt/claude-bridge/admin add --account personal --label Windows
```

В ответ на каждую команду появится строка JSON с двумя полями — `id` устройства и `token`. Скопируйте только значение `token` целиком, начиная с `cb_`. Вставьте его на соответствующем компьютере через **Claude Bridge → Подключить**. Тот же `--account personal` даёт общую историю на Mac и Windows. Для разных людей используйте разные имена аккаунтов.

Токен выдаётся при создании. Если потеряли его, создайте новый и отзовите старый по ID. VS Code хранит вставленный токен в SecretStorage.

```sh
sudo /opt/claude-bridge/admin list
sudo /opt/claude-bridge/admin revoke ID_УСТРОЙСТВА
```

Если также нужен графический рабочий стол, установите его отдельно из той же распакованной папки на VPS. Команда `sudo bash deploy/desktop/install.sh` устанавливает XFCE и xRDP. Затем назначьте пароль через `sudo passwd bridge-desktop` и используйте [инструкцию для удалённого рабочего стола](desktop.md).

## Ключ Claude API

**Вход в Claude Bridge** уже выполнен, когда расширение приняло токен `cb_`. Чтобы выбрать настоящую модель Anthropic внутри Claude Bridge, добавьте **ключ Claude API** на VPS. Для чата в браузере можно зайти в [Claude](https://claude.ai/). Для входа по подписке в официальном расширении используйте [Claude Code](https://code.claude.com/docs/en/vs-code). [Правила аутентификации Anthropic](https://code.claude.com/docs/en/legal-and-compliance)

Если хотите пользоваться именно официальным Claude Code по подписке, откройте **Extensions** в VS Code, найдите **Claude Code** от **Anthropic** и нажмите **Install**. Откройте его панель и завершите вход в аккаунт Claude в браузере. Чтобы подключить Claude к **Claude Bridge** через свой VPS, продолжайте со следующим шагом. [Руководство по официальному расширению](https://code.claude.com/docs/en/vs-code)

### 1. Получите ключ в Claude Console

1. Откройте [Claude Console](https://platform.claude.com/) в браузере и войдите в свой аккаунт Anthropic.
2. Откройте [Billing](https://platform.claude.com/settings/billing) и проверьте баланс или наличие доступных API-кредитов. Если у вас Claude Max, кредиты можно привязать к организации Console по официальной инструкции. Claude Pro даёт доступ к официальному Claude Code через подписку. Для Claude Bridge применяется отдельный баланс Claude API. [API-кредиты по подписке](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers)
3. Откройте [API Keys](https://platform.claude.com/settings/keys), нажмите **Create key**, выберите свою организацию или рабочее пространство, если Console предложит, и дайте ключу имя, например `Claude Bridge`.
4. Скопируйте выданный ключ полностью. Console показывает его при создании. [Инструкция Anthropic по созданию ключа](https://platform.claude.com/docs/en/get-api-key)

### 2. Вставьте ключ в файл на VPS

Откройте SSH-сеанс на VPS и запустите редактор:

```sh
sudo nano /etc/claude-bridge/backend.env
```

Найдите строки `ANTHROPIC_MODELS=` и `ANTHROPIC_API_KEY=` и заполните правую часть. Для первой настройки подойдёт пример с Claude Sonnet 4.6. В этом режиме API поддерживает обычные ответы и вызовы локальных инструментов через текущий backend. [Claude Sonnet 4.6](https://platform.claude.com/docs/en/models/sonnet-4-6/overview)

```dotenv
ANTHROPIC_MODELS=claude-sonnet-4-6
ANTHROPIC_API_KEY=ВСТАВЬТЕ_СВОЙ_КЛЮЧ_ИЗ_CONSOLE
```

Вставьте ключ только в этот серверный файл. В nano сохраните **Ctrl+O**, нажмите **Enter**, затем выйдите через **Ctrl+X**. Если в выбранной конфигурации Anthropic требует ID рабочей области, заполните `ANTHROPIC_WORKSPACE_ID=` значением из Console.

Примените настройки **на VPS**:

```sh
sudo systemctl restart claude-bridge
curl http://127.0.0.1:18765/healthz
```

Дождитесь, пока VS Code снова покажет **Сервер подключён**. Откройте список **Модель**, выберите **anthropic · claude-sonnet-4-6** и отправьте короткий вопрос. Тот же токен `cb_` продолжает подключать устройство к backend.

## Интерфейс расширения

Наведите указатель на кнопку, чтобы увидеть подсказку. На значки внутри чата можно перейти клавишей **Tab**, а закрыть подсказку клавишей **Esc**. Кнопка справки в заголовке открывает это руководство.

| Что видно | Что делает |
| --- | --- |
| ![Значок моста](../extension/media/bridge.svg) **Claude Bridge** слева | Открывает панель чата |
| **?** в заголовке панели | Открывает руководство |
| Цветная точка | Зелёная означает, что сервер подключён. Жёлтая показывает попытку подключения, красная — отказ в доступе, серая — что устройство ещё нужно подключить |
| **Подключить** | Открывает поле для токена устройства `cb_` |
| **Диалоги** | Открывает предыдущую переписку аккаунта |
| **+** | Создаёт новый диалог |
| **Модель** | Выбирает модель для следующего сообщения |
| **↥** | Прикрепляет текстовый файл из выбранной рабочей папки |
| **⌗** | Добавляет выделение из редактора. Сначала выделите нужный код |
| **×** рядом с именем вложения | Убирает вложение из следующего сообщения |
| **Доступ к рабочей папке** | Включает локальные инструменты для выбранной доверенной папки. При нескольких папках используется та, которую вы указали в соседнем списке |
| **Отправить** / **Стоп** | Отправляет запрос или отменяет текущую генерацию |
| **Применить изменение**, **Создать файл**, **Удалить файл**, **Выполнить** | Подтверждает предложенное действие. Правки можно проверить в VS Code Diff, а команду и рабочую папку — в панели |
| **Отклонить** | Отменяет предложенное действие |

### Попробуйте работу с файлами

1. В VS Code выберите **File → Open Folder…** и откройте папку **проекта, с которым хотите работать**. Для проверки подойдёт пустая папка. Подтверждайте доверие только для папки, содержимое которой знаете.
2. В панели чата включите **Доступ к рабочей папке**. С моделью **mock · mock** отправьте этот пример:

   ```text
   /mock [{"name":"list_directory"},{"name":"create_file","arguments":{"path":"bridge-test.txt","content":"Claude Bridge test\n"}}]
   ```

3. В VS Code откроется сравнение. Прочтите предлагаемое содержимое справа и нажмите **Создать файл** или **Отклонить** в чате.
4. С настоящей моделью можно писать обычным языком. Например, «Найди файл, в котором настраивается порт, и объясни, как его изменить». Для вопроса об одном фрагменте выделите код и нажмите **⌗**.

### Если что-то не получилось

| Симптом | Что проверить |
| --- | --- |
| Значок моста не появился | Проверьте, что установили файл `.vsix` в том VS Code, которым пользуетесь. Перезагрузите окно через **Developer: Reload Window** |
| Панель вечно подключается или показывает «Переподключение» | Оставьте окно с SSH-туннелем открытым. Проверьте `http://127.0.0.1:18765/healthz` из второго терминала. Если ответа нет, проверьте `sudo systemctl status claude-bridge` на VPS |
| SSH пишет `Host key verification failed` | Проверьте адрес и ключ хоста через доверенную веб-консоль VPS. Если это первый вход с компьютера, выполните обычный `ssh` и подтвердите только сверенный отпечаток |
| Расширение отклонило ключ | Для поля **Подключить** нужен токен `cb_` именно этого VPS. Ключ `sk-ant-` используется только в серверном файле Anthropic |
| Модель Anthropic не появилась | Проверьте, что редактировали `/etc/claude-bridge/backend.env` **на VPS**, задали ключ и ID модели и перезапустили `claude-bridge` |
| Anthropic возвращает ошибку авторизации или баланса | Проверьте ключ, организацию и её баланс в Console. Ошибки запуска смотрите командой `sudo journalctl -u claude-bridge -n 50 --no-pager` |
| Кнопки файлов серые | Откройте доверенную локальную папку и дождитесь завершения текущего запроса. Для **⌗** сначала выделите текст в редакторе |
