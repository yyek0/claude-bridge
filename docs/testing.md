Автоматическое переподключение WebSocket проверено в VS Code.

## Повторение

```sh
PYTHONPATH=backend .venv/bin/python -m unittest discover -s tests -v
npm run --prefix extension package
npm audit --prefix extension
```

`tests/smoke_vps.py` использует действующий SSH ControlMaster, указанный в `BRIDGE_TEST_SSH_CONTROL`, и адрес `BRIDGE_TEST_SSH_TARGET`. Скрипт создаёт три тестовых токена, проверяет соединения через локальный порт туннеля и отзывает токены. Команда запуска — `PYTHONPATH=backend .venv/bin/python tests/smoke_vps.py`.

Для `extension/test-ui.mjs` нужен отдельный профиль VS Code с установленным VSIX и включённым `files.simpleDialog.enable`. Откройте отдельную одноразовую рабочую папку с файлом-маркером `.claude-bridge-test-workspace` в её корне. Запустите VS Code с выделенными `--user-data-dir`, `--extensions-dir` и диагностическим портом Chromium, привязанным к `127.0.0.1`. Укажите `BRIDGE_TEST_PROJECT` и `BRIDGE_TEST_CDP`. Скрипт читает JSON с тестовым токеном из stdin и создаёт в тестовой папке временные файлы и Git-репозиторий. Параметры `BRIDGE_TEST_SSH_CONTROL` и `BRIDGE_TEST_SSH_TARGET` включают реальный перезапуск сервиса, поэтому их следует задавать только во время согласованной проверки. `BRIDGE_TEST_REVOKE=1` отзывает тестовый токен.

```sh
ssh -S "$BRIDGE_TEST_SSH_CONTROL" -o StrictHostKeyChecking=yes "$BRIDGE_TEST_SSH_TARGET" \
  "/opt/claude-bridge/admin add --account test-ui-$(date +%s) --label test-ui" |
  node extension/test-ui.mjs
```
